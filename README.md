# Data-Project-Comportamiento-de-ventas
Comportamiento de Ventas, Comercio Exterior o Retail Público

¿Qué categorías generan el 80% de los ingresos (Pareto)? ¿Cómo evolucionan las ventas año contra año (YoY)? ¿Qué regiones o segmentos tienen menor margen o mayor tasa de devolución/cancelación?

Datasets públicos recomendados:

Superstore Sales (Kaggle) o Online Retail II (UCI Machine Learning Repository): ideales para retail, márgenes, descuentos y cohortes de clientes.

Brazilian E-Commerce (Olist) (Kaggle): excelente porque viene dividido en múltiples tablas relacionales (órdenes, clientes, productos, pagos, reseñas), lo que te obliga a hacer un ETL real.

SECOP II (Datos Abiertos Colombia): si quieres darle un enfoque local de contratación y compras públicas.
